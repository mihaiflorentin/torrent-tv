## Deviations and reasons

- **Primary scale 1.045, not 1.06**: one lift value for posters and buttons (#53 decision).
- **Secondary pills use `--tt-fill` (0.10), not the board's 0.14**: 0.14 is `--tt-fill-selected`, the "selected" look (My List once added); keeping them apart keeps selection readable.
- **Rings are the solid outline, drawn square on Chromium 53/63** (the board's rounded `0 0 0 4px` shadow): the webOS validator and the focus contract need the outline (#53).
- **Rows are about 104 px, not 84 px**: the release and file name keeps its reserved line under the columns (shown on the focused row only), which DESIGN keeps as the evidence for the decision; the board omits it.
- **The primary label on Play** is "Play and download · 1080p WEB-DL" (the board shows only Resume); the size moved to the muted line, which follows the board's wording ("Plays 1080p WEB-DL · 4.2 GB · Downloaded"; for Play "Plays the Best match: …"). Codec, seeders and tracker stay on the rows.
- **Runtime and certification arrive a moment later**: `CatalogTitle` has neither, so the page asks the existing Info endpoint once, 400 ms after it opens, and adds them when the answer lands; the Info panel then opens on the same answer. Series show no runtime (the provider's runtime is per episode).
- **The fixture's resume points at a release the version list does not hold**, so the capture's plays line names the file ("Plays Quiet Echo: The Ember Archive.mkv"); with a matching version it names the version (tested).
- **Long titles wrap to two lines** at 88 px in the 1100 px column (the fixture's "Quiet Echo: The Ember Archive"), pushing the versions down to about y 830 instead of the board's 724.
- **The series page's season card and episode rows are unchanged** (#57); only its header and action row follow this board.
