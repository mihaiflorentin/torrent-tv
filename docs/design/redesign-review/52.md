# #52 New design tokens and the Inter font: screenshot review

What changed: values only. The shared tokens move to the Night Screen palette, the white focus colour and the new TV type scale, and Inter replaces Bricolage Grotesque on TV and in the browser. No screen layout was restyled. The one CSS edit outside the tokens: the Home hero title's two-line clamp is now `2.16em` instead of `140px`, so it still clips at a line boundary at the larger title size. Every TV screen takes the new values, so every screen changed a little and none matches its board yet. **Expect "half-new" screens**: the new ground, white type, Inter and a white focus ring, still inside the Velvet Booth layout (outlined boxes, saffron primary buttons, the boxed hero, Unicode rail glyphs). The later tickets (#53 vocabulary and focus, then the per-screen tickets) close that gap.

## How the captures were made

The capture script from #65 had not landed on the integration branch when this was done, so the TV captures use the research scripts (`shoot.mjs` and `shoot2.mjs` from the spec research). They drive the TV bundle in headless Chromium at 1920x1080 with the Tizen 5 user agent (lean graphics), against the `tools/tv_perf` fixture server. "Before" is the research set taken from the integration branch before this ticket; "after" is this branch with the same scripts and the same fixture. No browser-app captures were made: the browser app only took the token values, and its layout changes come with the browser alignment ticket.

Point by point, for every screen:

- **Layout and spacing:** unchanged, by design (values-only ticket). The only movement is the taller title type: the Home hero and the title pages gain one line where a title wraps.
- **Type:** Inter at the new sizes; meta 26, body 30, lead 34 (was 36), heading 56 (was 46), title 88 (was 64), display 92. The 26 px floor holds. Headings do not use the new tracking tokens yet; screens adopt them when restyled.
- **Colour and accent:** the ground, surfaces, text and status colours are the board's values. The accent is the board's `#f2a93b`, but the old layouts still use it as a primary-button fill and for the rail's active bar, which the boards reserve for progress and markers. That goes with #53 and the screen tickets.
- **Focus:** the ring and halo are now white (`0 0 0 5px rgba(255,255,255,0.25)` plus a drop shadow, as on the boards). The white focused fill (`--tt-fill-focus`) is defined but not applied yet (#53), so focus is still "ring around the existing fill".
- **Primary vs secondary actions:** unchanged from before (saffron primary fill, outlined secondaries). The boards' white-pill primary and icon-button secondaries come with #53.

## Deviations and reasons

- Screens do not match their boards: this ticket changes values only; the restyle is split across #53 to #64.
- Optical size is pinned to Inter's text design (14) rather than shipping the optical-size axis: the full axis roughly doubles the files (about 136 KB against 89 KB), and the TV inlines them into `app.css`. Titles at 80 to 92 px therefore use the text cut, slightly wider-spaced than Inter Display; the `-0.025em` tracking token tightens them when screens adopt it.
- Weight axis limited to 400 to 800 (the weights the direction uses) to keep the size down.
- `--tt-text-muted` keeps its name for the brighter muted tone (`#c9cdd6`, over art), and the quieter one is the new `--tt-text-subtle` (`#a8adba`, ground only): existing muted copy over the backdrop keeps clearing 4.5:1 without a screen change.
- No browser-app captures; its style contract passes with the new values and Inter was checked in the built bundle.
